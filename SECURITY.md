# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 3.3.x   | ✅        |
| < 3.3   | ❌        |

## Reporting a Vulnerability

Please **do NOT** open a public GitHub issue for security vulnerabilities, as this would expose the vulnerability before a fix is available.

Instead, report security issues by sending an email to:

📧 **andrea.terren@hpe.com**

### What to include in your report

- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential impact and severity
- Any suggested mitigation or fix (optional)

### What to expect

- We will acknowledge your report within **48 hours**
- We will keep you informed of the investigation progress
- Once a fix is released, we will credit you in the release notes (unless you prefer to remain anonymous)

## Scope

This security policy applies to the **Quantum-Safe-MACsec** project, including:

- QKD orchestration components
- KME (Key Management Entity) integration
- MACsec configuration and automation scripts
- All supported versions listed above

## Out of Scope

- Vulnerabilities in third-party dependencies (please report those to the respective maintainers)
- Issues in unsupported versions
