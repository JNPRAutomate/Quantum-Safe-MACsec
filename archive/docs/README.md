# Archived Documentation

The files in this directory preserve historical designs, experiments,
proposals, troubleshooting transcripts, and superseded release behavior.

They are not the source of truth for the current implementation and must not
be used as deployment or operational instructions without comparison against
the active documentation in [`docs/`](../../docs/readme.md).

## Archive convention

- Every archived Markdown file carries a standard archive banner.
- Historical commands, paths, identities, credentials, and architecture names
  are preserved for traceability and may no longer be valid.
- Broken repository-relative links are corrected where the original target
  still exists.
- Content is not rewritten to resemble the current design because doing so
  would destroy its historical meaning.
- Current supported behavior belongs under `docs/`.
- Planned behavior belongs in the
  [Product and Architecture Roadmap](../../docs/roadmap.md).
